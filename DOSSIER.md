# Tailwind — screenshot dossier

Game: **Tailwind** — an original open-world crime game at Port Vane International's
air cargo terminal at dawn. You are Rook Vane, cargo pilot turned smuggler, working
four story jobs before sunrise. All art is drawn in code (canvas 2D), all sound is
synthesized with WebAudio, zero external assets, zero network requests.

## Screenshots (1280x720 JPEG, taken in headless Chromium from the game itself)

1. **1-start.jpg** (66,225 bytes) — Title screen. The TAILWIND panel over the dawn

   cargo pilot turned smuggler. Four jobs before sunrise." HUD shows $120, 0 wanted
   stars, 100 HP; the M1 mission card and the minimap (top right) are visible.

3. **3-chase.jpg** (67,541 bytes) — Mission 3, "Runway Run". Three wanted stars, two

4. **4-complete.jpg** (68,739 bytes) — Story complete. The "DAWN ESCAPE — COMPLETE"

## Systems shown

- On-foot and driving play (baggage tug, cargo truck, fuel tanker, police interceptor)
- Traffic on a perimeter loop, ground-crew pedestrians, airport security guards
- Wanted system (0–5 stars): security chases at 1+, police interceptors at 3+
- Four story missions with cash payouts ($400 / $800 / $1,500 / $5,000)
- Combat (pistol, mouse-aimed), ramming, health + slow regen, busted screen
- HUD (cash, stars, health, mission card, speed) + minimap + save (localStorage)
